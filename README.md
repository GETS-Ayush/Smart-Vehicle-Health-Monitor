Smart Vehicle Health Monitor
Smart Vehicle Health Monitor is a predictive maintenance dashboard that analyzes vehicle components and forecasts maintenance needs using AI-based insights.

🚗 Features
Component health monitoring (Engine, Battery, Brakes, Tyres)
AI maintenance prediction
Vehicle health score
Risk level indicator
Complete vehicle diagnostic scan
Export report functionality
🧠 How It Works
The system simulates sensor readings and evaluates them against safe thresholds.
Based on the analysis, it predicts maintenance timelines and overall vehicle health.

🛠 Tech Stack
HTML
CSS
JavaScript
🎯 Use Case
Helps vehicle owners and fleet managers detect potential failures early and schedule preventive maintenance.

📌 Future Scope
Integration with real vehicle sensors (IoT)
Machine learning predictive models
